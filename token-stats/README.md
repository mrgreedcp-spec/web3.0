# Claude Code token 统计与周报

读取 Mac 本地的 `~/.claude/projects/**/*.jsonl`（Claude Code 自动保存的会话记录），按主题、模型、会话统计 token。
只读本地文件，**运行本身不消耗任何 token**。

## 立即看一次（最近 14 天，按主题）

```bash
python3 token-stats/token_stats.py
```

其他用法：`--days 30`、`--week`（上一个完整自然周，带周环比）、`--csv sessions.csv`（导出每个会话的明细）。

## 每周自动周报

```bash
bash token-stats/install.sh
```

装好后每周一 9:07（本机时间）生成上周的周报，存到 `~/outputs/token-reports/2026-W45.md` 这样的文件里，并弹出 macOS 通知（显示折算 token、环比和缓存节约比例）。Mac 需要在那个时间开机；如果当时在睡眠，launchd 会在唤醒后补跑。

## 指标说明

| 指标 | 含义 | 想让它 |
|---|---|---|
| 折算 token | 按计价倍率加权：普通输入 ×1、缓存写入 ×1.25/×2、缓存读取 ×0.1、输出 ×5。最接近实际花费 | 降 |
| 缓存节约比例 | 1 − 实际折算 ÷ 不用缓存时的折算。连续工作越多越高 | 升 |
| 新会话首轮固定开销 | 每个新会话第一次请求就要载入的上下文（系统提示、插件、技能列表）。停用插件后会下降 | 降 |
| 每次请求平均上下文 | 话题混在一个会话里、不 `/clear` 时会变大 | 降 |
| 短问答会话 | 提问不超过 2 次的会话，基本只付了固定开销 | 降 |

“节约比例”有两个看法：**缓存节约比例**看单周的使用习惯；**折算 token 环比**看这周比上周少花了多少。

## 调整主题分类

修改 `token_stats.py` 顶部的 `TOPICS` 关键词列表即可，按顺序匹配会话标题和第一条提问。

## 局限

- 只统计这台 Mac 上 Claude Code 的记录。claude.ai 网页/手机聊天、云端会话不在其中，账号总用量以 claude.ai 设置 → Usage 为准。
- Claude Code 默认只保留 30 天的会话记录，周报不受影响，但更早的数据无法回溯。
