## 2. 核心卖点（4 宫格）

**原色原味**
不用高温猛炸，菠萝蜜还是金黄色，秋葵还是翠绿色。一口咬下去，就是水果蔬菜本来的味道。

**低温工艺**
真空环境下，水在 40–60℃ 就会沸腾。我们用约 90℃ 的油温给食材"温柔脱水"，比常规油炸低 70℃ 以上。

**酥脆不腻**
水分在低温下迅速汽化，在果肉里留下细密的小孔，吃起来"咔嚓"一声脆。出锅前还会真空离心脱油，口感清爽不油腻。

**充氮锁鲜**
独立充氮包装，隔绝氧气和湿气。开袋就是刚出锅的脆度。

## 3. 工艺解读：什么是 VF？

**小标题**
VF = Vacuum Frying，真空低温油浴脱水

**正文**
山顶上烧水，不到 100℃ 就开了，因为气压低了，水的沸点也会跟着降低。

VF 工艺就是用的这个原理：把食材放进真空罐里，抽掉大部分空气，水的沸点就降到 40–60℃。这时只要约 90℃ 的油温，食材里的水分就能快速蒸发。果蔬不会被高温"炸焦"，颜色、香气和口感都能更好地保留下来。

**对比表**

| | 常规油炸 | VF 真空低温工艺 |
|---|---|---|
| 加工环境 | 常压 | 真空（约 -0.09 MPa） |
| 油温 | 160–190℃ | 约 80–105℃ |
| 颜色 | 易褐变、发暗 | 接近原料本色 |
| 风味 | 焦香掩盖本味 | 保留果蔬本味 |
| 口感 | 硬脆、偏油 | 酥松、清爽 |

## 4. 工艺流程（时间轴 / 步骤条）

1. **严选鲜果**：选用【产地】当季鲜果蔬，逐批挑拣。
2. **清洗切片**：清洗、去皮，切成均匀厚度的薄片。
3. **低温速冻**：零下【xx】℃ 速冻，冰晶撑开组织，让成品更蓬松。
4. **真空低温脱水**：真空状态下约 90℃ 油浴脱水，带走水分，留住风味。
5. **真空离心脱油**：在恢复常压之前高速离心甩油，减少油脂残留。
6. **充氮包装**：冷却后立即充氮密封，锁住酥脆。

## 8. 常见问题（FAQ）

**Q：VF 果蔬脆是油炸的吗？**
A：是的，VF 是在真空低温条件下用食用油给果蔬脱水，属于低温油浴工艺，含有一定油脂。和常规高温油炸相比，它的油温低得多，出锅前还会真空离心脱油。我们不会把它包装成"非油炸"产品。如果你想要完全不含油的果蔬干，可以看看我们的【FD 冻干系列】。

**Q：吃起来甜，是加了糖吗？**
A：甜味主要来自果蔬本身的糖分，低温工艺让它更好地保留了下来。部分口味在工艺中会使用【糖 / 麦芽糊精】，具体请以包装配料表为准。

**Q：开袋后怎么保存？**
A：开袋后请尽快吃完，或者用密封夹夹紧，放在干燥处。如果受潮变软，可以用烤箱 100℃ 烘 3–5 分钟，脆度就能恢复。

**Q：VF 和 FD 冻干有什么区别？**
A：VF 用低温油浴脱水，口感酥脆，带一点油香。FD 在零下低温里把冰直接升华掉，不用油，口感酥松、入口即化，价格也更高。两种工艺各有风味，按自己的喜好选就好。
