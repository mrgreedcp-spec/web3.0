# 数据清洗 Wiki（Obsidian）

`数据清洗 Wiki/` 是一个可以直接放进 Obsidian 的笔记文件夹，按 LLM Wiki 的方式组织：

- **一个概念一篇笔记**，用 `[[双链]]` 互相连接，在关系图里能看到它们的联系
- `00 索引`：所有笔记的目录，每篇一句话说明
- `01 日志`：按时间记录 Wiki 的变化
- `02 Wiki 规则`：页面怎么写、怎么链接、怎么更新。让 AI 帮你维护 Wiki 时，先让它读这一篇

原始资料（数据、脚本、清洗计划全文）不放进 Wiki，留在 Git 仓库里，每篇笔记开头的 `sources` 字段写明了链接。

## 放进 Obsidian

**方法一：放进你现有的库**
1. 把 `数据清洗 Wiki` 整个文件夹复制到你的 Obsidian 库所在的文件夹里（在 Finder 里拖进去就行）
2. 回到 Obsidian，左侧会自动出现这个文件夹。从 `00 索引` 开始看

**方法二：单独作为一个库打开**
Obsidian 左下角的库图标 → “打开本地仓库” → 选择 `数据清洗 Wiki` 文件夹

**以后自动同步（可选）**
在 Mac 上 `git clone` 这个仓库，再在 Obsidian 里用社区插件 Obsidian Git 拉取更新。
