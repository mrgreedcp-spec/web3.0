# 步骤 4 · 零运行时间

**同样是 0 小时，结合其他列分成两种情况：记录错误改为缺失，取消批次保留并标记。**

## 知识点
1. 同样是 0，要结合其他列判断原因
2. 用 `&` 组合条件，把情况分开
3. 值肯定错 → 改成 `NaN`（“不知道”比“0 小时”更诚实）
4. 一个字段错，不删整行
5. 真实情况保留原值，加布尔列 `cancelled`
6. 估算值再接近也不是真实值
7. 除以 0 悄悄得到 inf；`mean()` 悄悄跳过 NaN，见 [[零运行时间与 inf]]

## 推演过程
1. **对照其他列**

| | SIM-20261005-L1 | SIM-20261013-L3 |
|---|---|---|
| 合格产出 | 1135.1 | 0 |
| 能耗 | 550.8 | 3.2 |
| 结论 | 前后矛盾 → 记录错误 | 前后一致 → 像取消了 |

2. **代码**
   ```python
   zero = df["run_hours"] == 0
   a = zero & (df["good_output_kg"] > 0)
   b = zero & (df["good_output_kg"] == 0)
   df.loc[a, "run_hours"] = np.nan
   df["cancelled"] = b
   ```
3. **为什么不估算填补**：1181.4 ÷ L1 中位产能 117.1 ≈ 10.08 小时，真实值 10.42，差约 3%
4. **为什么不删情况 A**：会丢掉 1135.1 kg 合格产出和 550.8 kWh 能耗
5. **验证**：L1 平均产能，不处理是 **inf**，处理后是 **117.8**（基于 20 个批次）
6. **疑点**：取消批次投入量 1258 kg，原料真的投入了吗？并入待确认问题 Q3
