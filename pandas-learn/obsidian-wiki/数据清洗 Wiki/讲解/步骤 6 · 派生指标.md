# 步骤 6 · 派生指标

**先明确哪些行可以算，再只对这些行计算，从根本上避免 inf。54 / 60 个批次参与计算。**

## 知识点
1. `astype("category")`：取值少的文本列转类别类型
2. 用布尔列 `ok_for_efficiency` 明确写出“哪些行可以算”
3. `np.where(条件, 计算结果, np.nan)`：满足才算，否则 NaN
4. 手工验算一行，确认公式
5. 用已知设定检验结果
6. `groupby(..., observed=True)`：只显示实际出现的类别
7. 有标记不等于不能用：冲突记录仍参与计算，所以假设会影响结果

## 推演过程
1. **定义可以计算的行**
   ```python
   ok = ~df["cancelled"] & (df["run_hours"] > 0) & 三列都不缺
   df["kg_per_hour"] = np.where(ok, df["input_kg"] / df["run_hours"], np.nan)
   ```
2. **结果**：54 / 60；排除的 6 个 = 取消 1 + 缺运行时间 2 + 缺能耗 2 + 缺合格产出 1；inf 个数为 0
3. **取消批次**：`kg_per_hour = NaN`；直接相除会是 1258.0 ÷ 0.0 = inf
4. **手工验算 SIM-20261001-L1**

| 指标 | 计算 | 结果 |
|---|---|---|
| 合格率 | 1330.2 ÷ 1367.1 | 0.973 ✓ |
| 产能 | 1367.1 ÷ 11.67 | 117.1 ✓ |
| 每小时能耗 | 669.3 ÷ 11.67 | 57.4 ✓ |
| 单位产出能耗 | 669.3 ÷ 1330.2 | 0.503 ✓ |

5. **对照设定**

| 产线 | 合格率（设定） | 产能 kg/h（设定） | 每小时能耗（设定功率） |
|---|---|---|---|
| L1 | 95.6%（95%） | 117.8（120） | 55.3（55） |
| L2 | 91.9%（92%） | 98.7（100） | 48.3（48） |
| L3 | 90.8%（90%） | 139.2（140） | 62.5（62） |

都接近设定，说明前 5 步没有把数据弄坏。
