# 步骤 1 · 读取与复制

**只做准备，不改任何数据：读入文件、复制一份、加两列辅助列。**

## 知识点
1. `pd.read_csv(..., parse_dates=["date"])`：读取时就把日期转成日期类型
2. `df = raw.copy()`：原始数据和工作副本分开，见 [[原始数据只读]]
3. 行号 = 索引 + 2：索引从 0 开始，CSV 第 1 行是表头
4. 辅助列 `raw_line`：删行、排序以后仍能追溯到原始文件的第几行
5. `issue_flags` 的初始值用 `""` 不用 `NaN`：`NaN` 和文字拼接，结果还是 `NaN`
6. `(条件).all()`：是否每一行都满足
7. 分步运行时每次都从原始文件重新开始，保证可以复现

## 推演过程
1. **现状**：63 行 × 8 列，`date` 是文本
2. **判断**：后面要按日期计算、要能追溯行号、要能给每行记录问题
3. **代码**
   ```python
   raw = pd.read_csv(RAW, parse_dates=["date"])
   df = raw.copy()
   df.insert(0, "raw_line", df.index + 2)
   df["issue_flags"] = ""
   ```
4. **结果**：63 行 × 10 列；`date` 是 `datetime64[us]`；第一行 `raw_line = 2`
5. **验证**：`(df["data_label"] == "SIMULATED").all()` → True，全部是模拟数据

SIM-20261001-L1：合格率 1330.2 ÷ 1367.1 = 97.3%，产能 1367.1 ÷ 11.67 = 117 kg/h，都接近 L1 的设定值。**看数据时随手算一两个指标**，能很快判断是否合理。
