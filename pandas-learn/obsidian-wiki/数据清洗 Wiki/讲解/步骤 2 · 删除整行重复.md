# 步骤 2 · 删除整行重复

**找出完全相同的行，删掉重复的那一份。63 行 → 61 行。**

## 知识点
1. `df.duplicated()`：这一行之前有没有出现过完全相同的行
2. `keep=`：`"first"` 保留第一条，`"last"` 保留最后一条，`False` 把所有重复的都标出来（用来查看）
3. `df[~dup]`：`~` 取反，只留下不重复的
4. **`subset=` 要排除辅助列**，否则一行也找不到，而且不报错
5. 删行后索引会出现缺口，追溯要靠 `raw_line`
6. 只删整行相同的；批次号相同、数值不同的留给 [[步骤 3 · 批次号冲突]]

## 推演过程
1. **现状**：SIM-20261002-L3、SIM-20261010-L1 各录了两次
2. **先看**：`keep=False` 显示第 7/8 行、第 30/31 行完全相同
3. **代码**
   ```python
   cols = [c for c in df.columns if c not in ("raw_line", "issue_flags")]
   dup = df.duplicated(subset=cols, keep="first")
   df = df[~dup]
   ```
4. **结果**：删掉第 8、31 行，63 − 2 = 61 行
5. **验证**：原件第 7、30 行还在；SIM-20261017-L3 仍有 2 条（数值不同，不算整行重复）

## 对照实验
| 写法 | 找到几行重复 |
|---|---|
| `df.duplicated(subset=cols)`，排除行号 | **2** ✓ |
| `df.duplicated()`，带上行号 | **0** ✗ |

## 小练习
- 去掉 `subset=cols` → 变成“找到 0 行”
- `df.duplicated(subset=["batch_id"]).sum()` 是 3，多出的 1 行就是冲突记录。想想为什么这一步不能这样写
