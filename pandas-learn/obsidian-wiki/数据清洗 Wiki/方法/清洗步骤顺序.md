# 清洗步骤顺序

**一般顺序：读取、复制 → 去重 → 解决冲突 → 修正明显错误 → 处理缺失 → 整理类型、计算指标 → 校验 → 导出。**顺序错了，结果会错。

## 为什么这样排
| 步骤 | 为什么排在这里 |
|---|---|
| 读取、复制 | 所有修改都在副本上做，见 [[原始数据只读]] |
| 去重 | **必须最先做**，不然后面的计数、平均值都会把重复的行算两次 |
| 解决冲突 | 去重之后剩下的，才是真正“同一编号、不同数值”的冲突，见 [[重复记录]] |
| 修正明显错误 | 比如把错误的 0 改成缺失，这样下一步能一起统计 |
| 处理缺失 | 包括上一步改出来的缺失，见 [[缺失值处理]] |
| 类型与指标 | 数据处理好了再算，避免算出 inf，见 [[零运行时间与 inf]] |
| 校验 | 确认达到验收标准，见 [[验收标准与 assert]] |
| 导出 | 另存为新文件，原始文件不动 |
