# 清洗脚本四原则

1. **一步只做一件事**：每一步写成一个函数，出了问题容易定位
2. **先看后改**：每一步都先把要改的行打印出来，再动手修改
3. **改了就记**：每处改动都写进 [[清洗日志]]：哪一步、哪条记录、改前改后、为什么
4. **最后验证**：用 assert 确认达到标准，见 [[验收标准与 assert]]

## 让脚本可以分步运行
加一个 `--step N` 参数，运行到第 N 步就停下并打印当时的数据，不写出文件。适合学习，也适合排查问题：
```bash
python3 pandas-learn/batch-sim/clean_batches.py --step 3
```

## 两个容易踩的坑
- **辅助列参与比较**：加了 `raw_line`（原始行号）以后去重，要用 `subset=` 排除它，否则重复的两行因为行号不同而不算重复
- **链式赋值**：`df[条件]["列"] = 值` 改的是临时副本，原表不变。要写成 `df.loc[条件, "列"] = 值`
