# 代码片段 · 清洗常用写法

> 从 `clean_batches.py` 里摘出来的可复用写法，都在 pandas 3.0.5 上运行过。

## 1. 读取、复制、记下原始行号
```python
raw = pd.read_csv(path, parse_dates=["date"])
df = raw.copy()
df.insert(0, "raw_line", df.index + 2)   # 第 1 行是表头
df["issue_flags"] = ""
```
→ [[步骤 1 · 读取与复制]]

## 2. 去重（排除辅助列）
```python
cols = [c for c in df.columns if c not in ("raw_line", "issue_flags")]
print(df[df.duplicated(subset=cols, keep=False)])   # 先看
df = df[~df.duplicated(subset=cols, keep="first")]  # 再删
```
→ [[步骤 2 · 删除整行重复]]

## 3. 按假设解决编号冲突（并留痕）
```python
drop = df["batch_id"].duplicated(keep="last")
df = df[~drop].copy()
assert df["batch_id"].is_unique
```
→ [[步骤 3 · 批次号冲突]]

## 4. 按情况分别处理
```python
zero = df["run_hours"] == 0
a = zero & (df["good_output_kg"] > 0)   # 记录错误
b = zero & (df["good_output_kg"] == 0)  # 取消批次
df.loc[a, "run_hours"] = np.nan
df["cancelled"] = b
```
→ [[步骤 4 · 零运行时间]]

## 5. 加标记（不重复标记）
```python
def add_flag(df, mask, flag):
    df.loc[mask, "issue_flags"] = (df.loc[mask, "issue_flags"] + ";" + flag).str.strip(";")

new = df[col].isna() & ~df["issue_flags"].str.contains(f"{col}_", regex=False)
add_flag(df, new, f"{col}_缺失")
```
→ [[步骤 5 · 缺失值标记]]

## 6. 记清洗日志
```python
log = []
def record(step, batch_id, action, before, after, reason):
    log.append({"step": step, "batch_id": batch_id, "action": action,
                "before": before, "after": after, "reason": reason})
pd.DataFrame(log).to_csv("cleaning_log.csv", index=False, encoding="utf-8-sig")
```
→ [[清洗日志]]

## 7. 安全地计算指标（不会出现 inf）
```python
ok = ~df["cancelled"] & (df["run_hours"] > 0) & df[["good_output_kg", "run_hours", "energy_kwh"]].notna().all(axis=1)
df["kg_per_hour"] = np.where(ok, df["input_kg"] / df["run_hours"], np.nan)
assert not np.isinf(df["kg_per_hour"]).any()
```
→ [[步骤 6 · 派生指标]]

## 8. 合计时写明基于多少行
```python
df.groupby("line", observed=True)["energy_kwh"].agg(["sum", "count", "size"])
df["energy_kwh"].sum(min_count=len(df))   # 有缺失就返回 NaN
```
→ [[缺失值处理]]

## 9. 校验：一次报出所有失败
```python
checks = {"批次号唯一": df["batch_id"].is_unique, ...}
for name, ok in checks.items():
    print(f"  {'✓' if ok else '✗'} {name}")
failed = [name for name, ok in checks.items() if not ok]
assert not failed, f"校验失败：{failed}"
```
→ [[步骤 7 · 校验]]
