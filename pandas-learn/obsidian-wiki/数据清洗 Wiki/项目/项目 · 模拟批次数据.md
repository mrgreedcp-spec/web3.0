# 项目 · 模拟批次数据

> ⚠️ **全部为模拟数据**：固定随机种子生成，产线 L1/L2/L3、批次号、参数都是虚构的，不含任何真实或机密信息，不涉及任何客户。

## 概况
| 项目 | 内容 |
|---|---|
| 内容 | 2026-10-01 至 10-20，3 条产线，每条每天一个批次 |
| 字段 | 日期、批次、产线、投入 kg、合格产出 kg、运行小时、能耗 kWh，外加模拟标注 |
| 原始数据 | 63 行 = 60 个批次 + 3 行重复 |
| 清洗结果 | 60 行，10 项校验全部通过 |
| 仓库位置 | `pandas-learn/batch-sim/` |

## 清洗后的产线指标（54 个数据齐全的批次）
| 产线 | 平均合格率 | 平均产能 kg/h | 平均每小时能耗 kWh/h |
|---|---|---|---|
| L1 | 95.6% | 117.8 | 55.3 |
| L2 | 91.9% | 98.7 | 48.3 |
| L3 | 90.8% | 139.2 | 62.5 |

和模拟设定一致（L1 设定合格率 95%、产能 120 kg/h……），说明清洗没有把数据弄坏。

## 怎么运行
```bash
python3 pandas-learn/batch-sim/make_sim_data.py
python3 pandas-learn/batch-sim/check_issues.py
python3 pandas-learn/batch-sim/clean_batches.py --step 3
```
分别是：生成数据、按业务规则检查、分步清洗（去掉 `--step 3` 就跑完全部 8 步并导出）。
