# 原始数据只读

**原始文件永远不改，所有修改都在副本上做，结果另存为新文件。**改坏了随时可以从头再来，也能证明清洗前的数据是什么样子。

## 三道保护
1. **代码里复制**：`raw = pd.read_csv(...)`，`df = raw.copy()`，之后只改 `df`
2. **文件另存**：清洗结果存为 `batches_clean_SIMULATED.csv`，不覆盖 `batches_raw_SIMULATED.csv`
3. **校验值**：记下原始文件的 SHA-256，清洗前后各算一次，一致就说明没被改过
```bash
sha256sum pandas-learn/batch-sim/data/batches_raw_SIMULATED.csv
```

## 记下原始行号
`df.insert(0, "raw_line", df.index + 2)`：加 2 是因为索引从 0 开始、CSV 第 1 行是表头。删行、排序以后，仍然能找回“这一行在原始文件的第几行”。
