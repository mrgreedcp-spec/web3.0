# 自助法置信区间

**两条线的平均值不一样，差距可能是真的，也可能只是运气。自助法通过反复抽样，估计“如果再来一批数据，平均值大概会落在什么范围”。**

## 做法
1. 从一条线的批次里**有放回地**抽出同样多的批次（有的会被抽到两次，有的一次也抽不到）
2. 算这次抽样的平均值
3. 重复 10,000 次，得到 10,000 个平均值
4. 取中间 95% 的范围（第 2.5 到第 97.5 百分位），就是 95% 置信区间

```python
rng = np.random.default_rng(20261105)   # 固定种子，结果可复现
means = rng.choice(x, size=(10_000, len(x))).mean(axis=1)
lo, hi = np.percentile(means, [2.5, 97.5])
```

## 判断两条线的差距
对两条线分别抽样，相减，再看差值的 95% 区间：

| 情况 | 判断 | 例子 |
|---|---|---|
| 区间不包含 0，离 0 很远 | 差距可信 | 合格率 L1 − L2：+2.6 ～ +4.7 个百分点 |
| 区间不包含 0，但一端几乎碰到 0 | 可信但很弱 | 合格率 L2 − L3：+0.1 ～ +2.1 个百分点 |
| 区间包含 0 | 看不出差别 | 单位产出能耗 L1 − L3：−0.019 ～ +0.013 |

## 注意
- 样本少的时候区间会很宽，“看不出差别”不等于“没有差别”
- 不需要额外安装统计库，numpy 就能做
