# 缺失值处理

**同样是缺失值，处理方法取决于数据拿来做什么：统计分析可以接受估计值，记账性质的数据不能凭空编数字。**

## 两个对照例子
| | 泰坦尼克号乘客数据 | 模拟批次数据 |
|---|---|---|
| 用途 | 统计分析（谁更可能幸存） | 生产记录，相当于“账” |
| 缺失 | 年龄缺 177 个（20%） | 合格产出、运行时间、能耗共缺 4 个 |
| 处理 | 按称谓分组填中位数，并加 `age_imputed` 标记 | **不填补**，保留为空，加标记，等记录人补录 |
| 理由 | 估计值对统计结论影响可控 | 编出来的数字会被当成真实记录 |

## 按缺失比例的一般做法
| 缺失比例 | 常见做法 |
|---|---|
| 很少（几个） | 把这几行拿出来看；删掉，或填众数 |
| 中等 | 按相关的列分组填补，**并加标记列** |
| 很多（大半） | 改造成“有没有”的标记列，或删掉这一列 |

## 要注意
- pandas 求和时会**默默跳过**缺失值，合计偏低却没有提示
- 填补会让分布显得更集中：泰坦尼克号年龄填补后，标准差从 14.53 降到 13.27
- 有缺失值的整数列会变成小数（`2` 显示成 `2.0`）
