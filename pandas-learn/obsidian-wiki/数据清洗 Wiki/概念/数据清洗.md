# 数据清洗

**数据清洗是把原始数据变成“可以放心拿来分析”的数据的过程。**目标不是让数据看起来整齐，而是让基于它得出的结论可信。

## 整个流程
```
懂业务 → 保护原始数据 → 体检 → 列问题清单 → 写清洗计划 → 写脚本执行 → 校验 → 导出（附日志）
```

| 保护原始数据 | [[原始数据只读]] |

## 六条原则
1. 先懂业务，再动代码
2. 原始数据不动
3. 先查后改
4. 能保留就保留：异常值先查原因，不要一删了之
5. 改动要留痕：标记列和 [[清洗日志]]
6. 最后自动校验
