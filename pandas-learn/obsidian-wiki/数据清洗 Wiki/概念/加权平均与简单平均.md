# 加权平均与简单平均

**比例类指标（合格率、产能、单位能耗）有两种平均法：加权是先加总再相除，简单平均是每个批次算出比例再平均。批次大小差别大时，要用加权。**

## 两种算法
```python
# 加权：大批次占的比重大
s = ok.groupby("line")[["good_output_kg", "input_kg"]].sum()
weighted = s["good_output_kg"] / s["input_kg"]

# 简单平均：每个批次一票
simple = ok.groupby("line")["yield_rate"].mean()
```

## 例子
| | 加权合格率 | 简单平均合格率 |
|---|---|---|
| L3 | 90.96% | 90.81% |

这份模拟数据差别很小，因为批次大小都在 800～1600 kg。如果一个批次 10 kg、另一个 1000 kg，简单平均会把它们同等对待，结果就会失真。

## 以前也遇到过
模块 04 里，饮品的“平均单价”直接对单价求平均是 36.2 元；按件数加权（总金额 ÷ 总件数）才是 17.64 元。**问“平均每件 / 每公斤多少”，都要用加权。**
