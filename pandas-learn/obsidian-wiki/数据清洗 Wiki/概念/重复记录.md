# 重复记录

**重复分两种：整行完全相同的，确认后可以删；编号相同但数值不同的，不能自己挑，要先问人。**

## 整行重复
```python
cols = [c for c in df.columns if c not in ("raw_line", "issue_flags")]  # 比较时排除辅助列
dup = df.duplicated(subset=cols, keep="first")
df = df[~dup]
```
例子：SIM-20261002-L3、SIM-20261010-L1 各被录入两次 → 删除，63 行变 61 行。

**坑：**比较时要排除原始行号这类辅助列，否则重复的两行因为行号不同而不算重复。

## 编号相同、数值不同（冲突）
例子：SIM-20261017-L3 有两条记录，合格产出一条 840.9、一条 800.9。

- **不知道哪条是对的**，两条都留会重复计算，删哪条都是在猜
- 真实工作中要问记录人
- 练习时用了假设“后录入的是更正后的数据”（`keep="last"`），**并把这个假设写进 [[清洗日志]] 和 [[假设与待确认]]**

## 不处理的后果
投入、产出、能耗的合计都会偏高；日期越细，偏差越明显。
