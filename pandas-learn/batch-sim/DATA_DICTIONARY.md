> 产线 L1 / L2 / L3、批次号和所有参数都是虚构的，不对应任何真实工厂、公司、客户或人员，不含任何机密信息。

## 2. 字段说明

| 字段 | 中文名 | 类型 | 单位 | 格式 / 取值 | 必填 | 说明 |
|---|---|---|---|---|---|---|
| `data_label` | 数据标注 | 文本 | — | 固定为 `SIMULATED` | 是 | 标明这是模拟数据。**不能删除**，防止被误当成真实数据使用 |
| `date` | 生产日期 | 日期 | — | `YYYY-MM-DD` | 是 | 批次的生产日期。读入时用 `parse_dates=["date"]` 转成日期 |
| `batch_id` | 批次号 | 文本 | — | `SIM-YYYYMMDD-产线`，如 `SIM-20261001-L1` | 是 | 批次的唯一编号，以 `SIM-` 开头表示模拟。日期和产线必须与 `date`、`line` 一致 |
| `line` | 产线 | 文本（类别） | — | `L1` / `L2` / `L3` | 是 | 虚构的三条产线 |
| `input_kg` | 投入量 | 小数 | kg | 约 800–1600 | 是 | 投入这个批次的原料重量 |
| `good_output_kg` | 合格产出 | 小数 | kg | 0 ≤ 合格产出 ≤ 投入量 | 是 | 检验合格的产出重量，不含不合格品 |
| `run_hours` | 运行时间 | 小数 | 小时 h | 正常批次约 6–15 | 是 | 这个批次的实际运行时长。**正常生产的批次必须大于 0** |
| `energy_kwh` | 能耗 | 小数 | 千瓦时 kWh | 正常批次约 350–750 | 是 | 这个批次消耗的电量，包括约 5 kWh 的开机预热能耗 |

## 3. 常用的派生指标

这些指标不在文件里，分析时用已有的字段计算：

| 指标 | 公式 | 模拟设定的正常范围 | 注意 |
|---|---|---|---|
| 合格率 | `good_output_kg / input_kg` | 80%–100%；L1 约 95%，L2 约 92%，L3 约 90% | 合格产出缺失的批次不能算 |
| 产能（每小时投入量） | `input_kg / run_hours` | L1 约 120，L2 约 100，L3 约 140 kg/h | **运行时间为 0 时会悄悄得到无穷大（inf），不报错**，计算前必须先处理 |
| 每小时能耗 | `energy_kwh / run_hours` | L1 约 55，L2 约 48，L3 约 62 kWh/h | 同上 |
| 单位产出能耗 | `energy_kwh / good_output_kg` | 约 0.44–0.58 kWh/kg | 合格产出为 0 时会得到无穷大 |

## 4. 字段之间的业务规则

`check_issues.py` 会逐条检查下面这些规则：

| 编号 | 规则 |
|---|---|
| R0 | 每一行的 `data_label` 都必须是 `SIMULATED` |
| R1 | 不能有完全重复的行 |
| R2 | 同一个 `batch_id` 只能有一条记录 |
| R3 | 必填字段不能为空 |
| R4 | 有产出的批次，`run_hours` 必须大于 0 |
| R5 | 重量、时间、能耗都不能是负数 |
| R6 | 合格产出不能超过投入；合格率应在 80%–100% 之间 |
| R7 | 每小时能耗不应偏离本产线中位数超过 20% |
| R8 | `batch_id` 中的日期和产线，要与 `date`、`line` 一致 |

## 5. 模拟参数

全部为虚构的数值，写在 `make_sim_data.py` 里：

| 产线 | 产能 kg/h | 平均合格率 | 功率 kW |
|---|---|---|---|
| L1 | 120 | 95% | 55 |
| L2 | 100 | 92% | 48 |
| L3 | 140 | 90% | 62 |

- 投入量在 800–1600 kg 之间均匀随机
- 运行时间 = 投入量 ÷ 产能 × 随机系数（0.95–1.08）
- 合格率服从正态分布，标准差 1.5 个百分点，限制在 80%–99% 之间
- 能耗 = 运行时间 × 功率 × 随机系数（0.95–1.05）+ 5 kWh
